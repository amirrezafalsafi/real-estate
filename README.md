# 🏢 سامانه جامع املاک و مستغلات مسکن پلاس (Maskan Plus)

سامانه تخصصی و مدرن خرید، فروش، رهن و اجاره انواع آپارتمان، ویلا، املاک اداری، تجاری و زمین با معماری مدرن **Next.js 16 (App Router)**، کامپوننت‌های سرور، بهینه‌سازی کامل سئو و پنل مدیریت امن و پیشرفته.

---

## 🚀 ویژگی‌های کلیدی سامانه

- **رابط کاربری کاملاً فارسی و راست‌چین (RTL)** با فونت محلی زیبای **وزیرمتن (Vazirmatn)**.
- **نمایش بومی اعداد و ارقام**: قالب‌بندی کلیه قیمت‌ها و متراژها به زبان و ارقام فارسی همراه با جداکننده هزارگان (تومان).
- **صفحه اصلی پویا**: بنر هیرو با فرم جستجوی سریع، املاک ویژه، آمار سامانه، دسته‌بندی‌ها و فرم مشاوره هوشمند.
- **جستجو و فیلتر پیشرفته (`/properties`)**: فیلتر سرورساید بر اساس نوع معامله (فروش/اجاره)، نوع کاربری، شهر، منطقه، بازه قیمتی، بازه متراژ، حداقل خواب، امکانات (پارکینگ، آسانسور، انباری، بالکن) و مرتب‌سازی به همراه Pagination در آدرس URL.
- **صفحه اختصاصی هر ملک (`/properties/[slug]`)**: گالری چندرسانه‌ای با قابلیت لایت‌باکس تمام‌صفحه، جدول مشخصات فنی، لیست امکانات با آیکون، فرم درخواست هماهنگی بازدید متصل به ملک، پیشنهاد املاک مشابه و تولید متادیتای سئو و Open Graph داینامیک.
- **سیستم مقایسه تخصصی املاک (`/compare`)**:
  - استور کلاینت با محدودیت هوشمند حداکثر **۲ ملک** و هشدار در صورت تلاش برای افزودن ملک سوم.
  - نوار شناور ثابت در پایین صفحه (Floating Bar) با پیش‌نمایش کارت‌ها و دکمه فعال‌شونده مقایسه.
  - جدول مقایسه سرورساید دو ستونه و **هایلایت خودکار ارزش برتر (Best Value)** برای قیمت، متراژ، نوسازتر بودن و امکانات.
- **پنل مدیریت مستقل (`/admin`)**:
  - تفکیک کامل لایه‌بندی و عدم وجود هرگونه پیوند از سایت عمومی به ادمین.
  - احراز هویت امن با نشست‌های رمزنگاری‌شده JWT (`jose`) در کوکی‌های فقط‌خواندنی سرور (`httpOnly`).
  - محافظت از تمام صفحات ادمین با `middleware.ts`.
  - محدودکننده نرخ تلاش‌های ناموفق (Rate Limiting - حداکثر ۵ تلاش در ۱۵ دقیقه).
  - داشبورد آماری لحظه‌ای: تعداد کل املاک و تعداد درخواست‌های جدید و خوانده‌نشده.
  - مدیریت کامل املاک (CRUD): جستجو، فیلتر وضعیت، صفحه‌بندی، سوییچ سریع وضعیت و نشان ویژه، ویرایش، حذف با مودال تأیید.
  - فرم ثبت و ویرایش ملک با تولید خودکار نامک (Slug) از عنوان فارسی و اعتبارسنجی دوطرفه با Zod.
  - آپلود چندگانه تصاویر در `public/uploads` با قابلیت تغییر اولویت/ترتیب و حذف.
  - صندوق پیام‌ها و درخواست‌های مشاوره (`/admin/inquiries`) با تقویم شمسی (جلالی) و قابلیت علامت‌گذاری خوانده‌شده/حذف.
- **سئو و بهینه‌سازی فنی**:
  - تولید خودکار `sitemap.xml` و `robots.txt` (با مسدودسازی دسترسی موتورهای جستجو به `/admin`).
  - صفحات اختصاصی خطای ۴۰۴ فارسی و Error Boundary (`error.tsx`).
  - رندرینگ سریع با Partial Prerendering (PPR) و کش سرور با `revalidatePath`.

## 🛠 فناوری‌ها و ابزارها (Tech Stack)

- **فریم‌ورک اصلی**: Next.js 16.4 (App Router & Server Actions)
- **زبان**: TypeScript 5
- **استایل‌دهی**: Tailwind CSS v4
- **پایگاه‌داده و ORM**: Prisma ORM 7 با درایور SQLite (`file:dev.db`) با قابلیت سوئیچ آنی به PostgreSQL
- **مدیریت استیت سرور**: TanStack React Query v5
- **اعتبارسنجی**: Zod و Yup
- **امنیت و احراز هویت**: Jose (Edge-ready JWT) و Bcryptjs
- **آیکون‌ها**: Lucide React

## ⚙️ راهنمای راه‌اندازی و اجرا

### ۱. پیش‌نیازها
- Node.js نسخه 20 به بالا
- ابزار npm یا pnpm

### ۲. نصب وابستگی‌ها
```bash
npm install
```

### ۳. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس نمونه ایجاد کنید:
```env
DATABASE_URL="file:dev.db"
ADMIN_JWT_SECRET="your-super-secure-admin-secret-key-at-least-32-chars"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

### ۴. همگام‌سازی دیتابیس و اجرای Seed اولیه
برای ساخت جداول و وارد کردن ۱۸+ ملک واقع‌گرایانه و کاربر پیش‌فرض مدیر:
```bash
npx prisma db push
npx prisma db seed
```

### ۵. اجرای سرور توسعه (Development)
```bash
npm run dev
```
سامانه در آدرس `http://localhost:3000` در دسترس خواهد بود.

### ۶. بیلد پروداکشن (Production Build)
```bash
npm run build
npm start
```

## 🔐 ورود به پنل مدیریت (Admin)

- **آدرس صفحه ورود**: `http://localhost:3000/admin/login`
- **ایمیل پیش‌فرض**: `admin@maskanplus.ir`
- **کلمه عبور پیش‌فرض**: `Admin@123456`

### ایجاد کاربر مدیر جدید به صورت دستی
برای ساخت کاربر ادمین دیگر، می‌توانید از اسکریپت ساده زیر در محیط Node استفاده کنید:
```javascript
const { PrismaClient } = require("@prisma/client");
const { PrismaLibSql } = require("@prisma/adapter-libsql");
const bcrypt = require("bcryptjs");

const adapter = new PrismaLibSql({ url: "file:dev.db" });
const prisma = new PrismaClient({ adapter });

async function createAdmin(email, name, password) {
  const hash = bcrypt.hashSync(password, 10);
  const user = await prisma.adminUser.create({
    data: { email, name, passwordHash: hash }
  });
  console.log("مدیر جدید ایجاد شد:", user.email);
}

createAdmin("newadmin@maskanplus.ir", "مدیر همکار", "Password@123");
```

## 🔄 مهاجرت از SQLite به PostgreSQL

پروژه به گونه‌ای پیکربندی شده است که جابجایی بین SQLite و PostgreSQL تنها با تغییر تنظیمات انجام می‌شود:

1. در فایل `prisma/schema.prisma` خط ۹ را تغییر دهید:
```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```
2. در فایل `.env` آدرس اتصال دیتابیس PostgreSQL خود را قرار دهید:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/maskan_plus?schema=public"
```
3. دستور مایگریشن را اجرا نمایید:
```bash
npx prisma db push
npx prisma db seed
```
لایه‌بندی `lib/prisma.ts` و `server/services` به صورت خودکار با درایور `@prisma/adapter-pg` هماهنگ شده و برنامه بدون نیاز به هیچ تغییری در کدهای فرانت‌اند یا سرویس‌ها به کار خود ادامه می‌دهد.

```
├── app/
│   ├── (admin)/                 # مسیرهای ایزوله پنل مدیریت (/admin)

│   │   ├── properties/          # لیست و جزئیات هر ملک (/properties/[slug])
│   │   └── page.tsx             # صفحه اصلی (Landing Page)

│   └── ui/                      # کامپوننت‌های پایه (دکمه، اینپوت، نشان، اسکلتون)

│   ├── admin-auth.ts            # توابع احراز هویت و توکن JWT (jose)

│   ├── rate-limit.ts            # ماژول مهار حملات و محدودسازی لاگین
│   └── validations/             # اسکیماهای اعتبارسنجی Zod و Yup
├── prisma/
│   ├── schema.prisma            # شمای مدل‌های داده
│   └── seed.ts                  # اسکریپت سید نمونه‌ها با داده‌های فارسی
├── server/
│   ├── actions/                 # سرور اکشن‌های ثبت، ویرایش، حذف املاک و پیام‌ها
│   └── services/                # لایه سرویس کوئری‌ها و فیلترهای پایگاه‌داده
└── public/
    └── uploads/                 # محل ذخیره‌سازی تصاویر آپلود شده
```
